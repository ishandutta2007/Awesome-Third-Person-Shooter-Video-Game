# Awesome-Third-Person-Shooter-Video-Game

# Top Third-Person Shooter Video Game Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Open-Source Shooters, Game Engines & TPS Templates*  
**Last updated: October 2026**

This repository tracks notable **commercial third-person shooters** and **open-source projects** that provide production-ready TPS frameworks, multiplayer engines, and complete open-source shooter games. The TPS genre is defined by camera placement behind and above the character, enabling tactical awareness and character-driven combat.

**Examples** include Gears of War, The Division 2, Warframe, Outriders, Remnant 2, Spec Ops: The Line, Max Payne 3, Binary Domain, Army of Two, and Vanquish (the category leaders).

**Open-source emphasis**: The open-source ecosystem for TPS games is anchored by **Godot's official TPS Demo** (1,000+ stars) and **GDQuest's third-person controller**, while **RustCycles** and **MadWorld** demonstrate full open-source TPS projects in production. **RobustToolbox** provides a multiplayer engine foundation, and **Eternal Crusade Resurrection** offers a complete UE5 TPS template. This section is heavily expanded.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Gears of War](https://www.gearsofwar.com/)**  
  Microsoft's flagship TPS franchise with cover-based combat, co-op campaigns, and Horde mode. **The definitive third-person shooter** — established the modern cover shooter formula.

- **[Tom Clancy's The Division 2](https://www.ubisoft.com/game/the-division-2)**  
  Ubisoft's looter-shooter with RPG mechanics, open-world Washington D.C., and Dark Zone PvP. **The leading open-world TPS**.

- **[Warframe](https://www.warframe.com/)**  
  Digital Extremes' free-to-play TPS with space ninja combat, extensive customization, and years of content updates. **The most successful free-to-play TPS**.

- **[Outriders](https://www.outriders.com/)**  
  People Can Fly's co-op RPG shooter with class-based abilities and loot systems.

- **[Remnant 2](https://www.remnantgame.com/)**  
  Gunfire Games' souls-like TPS with procedural generation and challenging co-op combat.

- **[Spec Ops: The Line](https://www.specopstheline.com/)**  
  Yager Development's narrative-driven TPS with psychological depth and moral choices. **The critical darling of the genre** — praised for its storytelling.

- **[Max Payne 3](https://www.rockstargames.com/maxpayne3)**  
  Rockstar's stylish TPS with bullet time mechanics and cinematic presentation.

- **[Binary Domain](https://www.binarydomain.com/)**  
  Sega's sci-fi TPS with squad commands and destructible robot enemies.

- **[Army of Two](https://www.ea.com/games/army-of-two)**  
  EA's co-op TPS focused on two-player tactics and aggro management.

- **[Vanquish](https://www.vanquishgame.com/)**  
  PlatinumGames' fast-paced TPS with sliding mechanics and frenetic combat.

## Open-Source GitHub Projects

- **[Godot Third Person Shooter Demo](https://github.com/godotengine/tps-demo)**  
  **The official Godot Engine TPS demo** with 1,000+ GitHub stars and high-quality assets and lighting . **The most polished open-source TPS reference implementation** — demonstrates best practices for character controllers, camera systems, and 3D rendering in Godot . Actively maintained by the Godot team.

- **[GDQuest Godot 4 3D Third-Person Controller](https://github.com/gdquest-demos/godot-4-3d-third-person-controller)**  
  **Plug-and-play 3D TPS character controller** inspired by Ratchet and Clank, with 680+ GitHub stars . Features robust movement, camera control, and animation integration. **The best starting point for building a Godot 4 TPS** — designed as a reusable asset.

- **[RustCycles](https://github.com/rustcycles/rustcycles)**  
  **Fast multiplayer TPS arena shooter** written in Rust using the Fyrox engine, AGPL-v3 licensed . Focused on **movement-based combat** rather than aiming precision . Prototype stage with basic physics and networked projectiles. Goal: fully moddable multiplayer playable in browser and natively on Linux, Windows, and macOS . **The only open-source Fyrox game using networking** — shares architecture with RecWars .

- **[MadWorld](https://www.linuxfoundation.org/press/open-3d-foundation-announces-madworld-mobile-game-built-on-o3de)**  
  **Third-person shooter for iOS and Android** built on the Open 3D Engine (O3DE) — the first mobile title powered by O3DE . Developed by Carbonated, Inc. with strategic map gameplay, territory control, and multiplayer shootouts . **Demonstrates O3DE's viability for production TPS games** .

- **[Eternal Crusade Resurrection (ECR)](https://github.com/JediKnightChan/EternalCrusadeResurrection)**  
  **Unreal Engine 5 multiplayer TPS C++ project** — a resurrection of Warhammer 40K: Eternal Crusade . Built using **UE best practices from Lyra** with more complex behavior . Features **modular character customization**, **Epic Online Services P2P matchmaking** with Linux dedicated servers, **Lyra's GAS-based 3rd person multiplayer shooter and melee combat**, **vehicles as pawns**, **replication graph** for higher player counts, and **cross-platform code** (Windows, Linux, Android) . **Can be used as a template for creating similar genre games** — ECRCommon module contains broadly useful functionality.

- **[RobustToolbox](https://github.com/space-wizards/RobustToolbox)**  
  **Robust multiplayer game engine** used by Space Station 14, primarily developed for SS14 but working toward general singleplayer and multiplayer usability . 613+ GitHub stars, C# based . **Provides a solid foundation for building multiplayer TPS games** — though requires the content repo for actual development .

- **[Third Person Shooter with Shooter AI (baponkar)](https://github.com/baponkar/Third-Person-Shooter-With-Shooter-AI)**  
  **Unity TPS project with NPC shooter AI** controlled by state machine, similar to PUBG or Call of Duty . Features player locomotion (jump, shoot, reload, weapon change), **AI cover and hide ability**, minimap, **Shooter Navmesh AI with states** (Patrol, Find Weapon, Find Target, Death, Attack, ChaseTarget), three raycast weapons (Pistol, Rifle, Sniper), and weapon pickup for player and AI . Requires external Unity Asset Store packages and Mixamo characters . **Best for learning TPS AI implementation in Unity** .

- **[Yet Another Zombie Horror (YAZH)](https://github.com/UstymUkhman/YetAnotherZombieHorror)**  
  **Simple first/third person zombie survival shooter** built with TypeScript, Three.js, and Svelte . Runs in browser and as Electron desktop app . Features physics engine choice (ammo.js or three-mesh-bvh), configurable visuals (fog, rain, clouds, lighting), and third-person camera mode . **Best for web-based TPS experimentation** .

- **[Gode TPS Demo](https://github.com/godothub/gode-tps-demo)**  
  **Third-person shooter demo** made with Godot Engine and TypeScript via Gode . Features mouse/gamepad look and movement, jump, aim (toggle or hold), shoot (only while aiming), and debug info toggle . **Demonstrates TypeScript workflow in Godot** for developers preferring typed languages .

### Additional Strong Open-Source Options

- **Godot Engine** — Open-source game engine with full 3D support, GDScript/C#/TypeScript scripting, and the official TPS demo as reference .
- **Open 3D Engine (O3DE)** — Open-source game engine from the Open 3D Foundation, used to build MadWorld TPS for mobile .
- **Fyrox Engine** — Rust-based open-source game engine powering RustCycles, with networking support .
- **Third Person Shooter Controller (Gears-inspired)** — Unity TPS controller inspired by Gears of War, 29+ stars .

**Frameworks for building custom TPS solutions**: Combine **Godot TPS Demo** for a production-quality reference implementation with high-quality assets , **GDQuest TPS Controller** for plug-and-play character mechanics , and **Eternal Crusade Resurrection** for a complete UE5 multiplayer TPS template with EOS matchmaking and GAS combat . Use **RustCycles** for Rust/Fyrox multiplayer networking reference , **RobustToolbox** for multiplayer engine foundations , or **MadWorld** for O3DE mobile TPS validation . For Unity developers, **baponkar's TPS with AI** provides state machine NPC implementation . Note that true AAA TPS production with proprietary engines, motion capture, and global multiplayer infrastructure remains primarily commercial territory; open-source stacks provide strong character controllers, AI systems, and multiplayer foundations that require integration for complete TPS development.

## Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.
- Open-source TPS projects vary significantly in maturity. **RustCycles is a prototype** with no real gameplay yet , while **Godot TPS Demo** and **GDQuest Controller** are production-quality reference implementations .
- **Eternal Crusade Resurrection** requires the private ECRContent repository for full functionality — the public repo contains code but not game assets .
- **Unity TPS projects** like baponkar's require external Asset Store packages and Mixamo characters to function — they are not self-contained .
- The open-source ecosystem provides strong character controllers, AI systems, and multiplayer foundations, but **AAA production values, motion capture, and global multiplayer infrastructure** remain primarily commercial offerings.
